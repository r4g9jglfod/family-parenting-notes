# 当舌头“长”出癌症

> 更新时间：2026-09-16 (UTC+8)

**当舌头“长”出癌症**

2024年11月19日，著名歌手张咪的一个视频登上热搜，她自诉第三次患癌（前两次是扁桃体癌和口咽癌），舌头上长出新的东西，确诊为舌癌，将切掉半截舌头，可能将无法继续唱歌甚至是说话。

舌癌是是常见的口腔癌，是一种发生在舌头上的恶性肿瘤，它以隐匿的早期症状和凶险的后果，威胁着人们的口腔健康。舌癌可发生在舌体的任何部位，但以舌缘和舌下面两侧最为多见。舌癌多发于中老年人，男性略多于女性。据统计，我国每年新发舌癌患者约1.5万人，且发病年龄有年轻化的趋势。舌癌98%以上为鳞状细胞癌，腺癌较少，恶性程度较高、生长快、浸润性较强，常波及舌肌，致吞咽、发音、进食困难。晚期舌癌可蔓延至口底及下领骨，使全舌固定，部分晚期舌癌患者伴有扩散至半侧头面部的剧烈疼痛。另一方面因舌体具有丰富的淋巴管和血液循环，加以舌的机械运动频繁，在舌癌发展早期癌细胞就可发生转移，从而导致更大范围的损害（多为颈淋巴结和肺部）。

那么，这个“藏在舌头”的“杀手”，到底有哪些危险因素，它是如何一步步侵蚀我们的健康？面对舌癌的威胁，我们该如何提早预防，及时发现？

**舌癌的危险因素**

1.吸烟，肯定是舌癌的头号“凶手”。香烟中含有大量的致癌物质，如亚硝胺、苯并芘等。这些物质在口腔高温环境下，会直接刺激、损伤舌黏膜，诱发基因突变，促进癌变。研究表明，吸烟者患舌癌的可能性是不吸烟者的3-5倍。

2.饮酒，也是导致舌癌的重要因素。酒精不仅对口腔黏膜有直接刺激作用，还可增强致癌物质的作用。长期大量饮酒者，患舌癌的风险明显增加。

3.不良的口腔卫生习惯，也是舌癌的“导火索”。口腔卫生不良，会导致牙菌斑堆积，细菌滋生，引起慢性炎症，增加舌癌的发病风险。尤其是长期舌侧缘的机械性刺激，更是舌癌的高危因素。

此外，营养不良、免疫力低下、人乳头瘤病毒(HPV)等也都可能参与舌癌的发生过程。

**舌癌的早期症状**

舌癌的早期症状多隐匿，不易察觉，它们或是一个无痛的溃疡，或是一个轻微的色素斑，很容易被人忽视。但只要我们仔细观察，这些看似“平常”的症状，实际上是舌癌的早期信号。
1.溃疡或肿块：舌癌早期出现的溃疡常被患者自认为是“口腔溃疡”未予重视，但一般口腔溃疡可在2周内愈合，癌性溃疡常经久不愈，且溃疡面逐渐增大，并突出于舌体表面。有的舌癌以质地坚硬的肿块为症状，患者会感觉到“异物感”。
2.疼痛出血：舌部癌变后，会出现伸舌、吞咽时疼痛，易被患者误认为是“上火”。部分舌癌的患者进食时，食物经过病变部位，对伤口、创面的刺激也会导致疼痛。
3.舌体运动障碍：当癌变部位侵犯到舌肌时，会导致舌的运动障碍，常表现为伸舌歪斜，吞咽口水的时候有哽咽的感觉，严重者甚至在吃饭时难以下咽。部分患者会出现口齿不清、口吃症状。
**舌癌的检查与诊断**

1.口腔检查：通过口内的检查，观察舌体及肿块的大小、颜色、质地等，必要时行口腔镜检查。

2.影像学检查：如X光、CT、MRI等，有助于判断肿瘤的大小、位置以及与周围组织的关系，PET-CT检查还可以评估有无远处转移。

3.组织学检查：通过取活检组织进行病理学检查，以帮助确诊舌癌。必要时还需要免疫组化等特殊染色，来明确诊断。

**舌癌的综合治疗**

1.手术治疗。对于早期、局限性舌癌，手术可以彻底切除肿瘤，同时清扫区域淋巴结，根治癌症。随着微创技术的进步，激光手术、机器人辅助手术等新方法不断涌现，使舌癌手术更加精准、微创、安全。肿瘤切除后的功能重建，如游离皮瓣移植等，也大大改善患者的生活质量。

2.放射治疗。是舌癌治疗中的重要手段。方法有常规外照射、近距离照射等。放疗可以作为手术的辅助，减少局部复发；也可以作为姑息治疗，缓解晚期肿瘤引起的疼痛、出血等症状。

3.化学治疗。对于局部晚期、淋巴结转移的舌癌，也是必不可少的。常用的药物有顺铂、5-氟尿嘧啶等。化疗可以与放疗同步进行，增强放疗效果；也可以在手术前后进行，降低肿瘤负荷，杀灭残留癌细胞。

4.靶向治疗，针对肿瘤特异性分子，阻断生长信号通路。

5.免疫治疗，通过调动机体自身免疫力，实现对肿瘤的精准打击。

总之，舌癌的治疗需要口腔科、头颈外科、肿瘤科、护理部、营养科、心理科等多学科协作，为每一个患者量身定制最优化的综合治疗方案。只有多管齐下，精准施策，我们才能有效控制肿瘤，延长生存时间，提高生活质量。

**舌癌的预防与防治**

1. 养成良好的生活习惯：戒烟、限酒、避免嚼食槟榔等有害行为。
2. 注意口腔卫生：要坚持早晚刷牙、饭后漱口、定期洗牙，保持口腔清洁，减少口腔炎症的发生。

3.注意饮食均衡，多吃新鲜蔬菜水果，避免辛辣刺激食物，维护口腔黏膜健康。

4. 增强免疫力：保持良好的生活习惯，如规律作息、合理饮食、适度运动等，以提高身体免疫力。

5. 定期检查：对于高危人群，如长期吸烟、饮酒者，口腔黏膜白斑等，定期进行口腔检查，及时发现并治疗口腔疾病，预防舌癌的发生。

6.要加强舌癌防治知识的普及，提高公众的防癌意识；完善舌癌的筛查和早诊早治网络，早发现舌癌，早治疗。

让我们从现在做起，从自己做起，以科学的态度，积极的行动，共同筑就一道口腔健康的防线，守护好自己的舌头健康。
