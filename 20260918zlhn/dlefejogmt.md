# 潍坊试管党必看！第一次失败后，第二次进周要做这些检查，少查一项都可能再翻车

> 更新时间：2026-09-18 (UTC+8)

首先要明确核心原则：潍坊第二次试管进周，“不盲目重复查，也不轻易省略查”。距离第一次进周不满6个月，部分基础检查（如染色体）可沿用旧报告；但超过6个月、或第一次失败原因不明，必须重点补查“子宫、免疫、胚胎”相关项目——就像潍坊修潍县萝卜，第一次没种成，第二次得先查土壤、浇水时机，再调整种植方法，而不是直接重复种。

　　一、先分清：哪些检查能“沿用旧报告”，哪些必须“重新查”（潍坊医院通用标准）

　　很多潍坊姐妹不想多花钱、多遭罪，纠结哪些检查能省，其实按“时间+项目类型”划分，清晰又明确，潍坊正规医院均认可以下标准：

　　- 可沿用旧报告（满足1个条件即可，最多保留1年）：

　　1. 染色体检查（夫妻双方）：染色体终身不变，第一次查过正常，第二次不用再查，节省2000-3000元；

　　2. 传染病筛查（乙肝、丙肝、梅毒、艾滋）：结果有效期6-12个月，若第一次失败后6个月内启动第二次进周，可直接用旧报告；

　　3. 血型+RH因子：终身不变，第一次查过的报告，第二次进周时带好即可，不用重复抽血。

　　- 必须重新查（无论间隔多久，第二次进周必做）：

　　1. 女方卵巢功能评估（AMH值+基础卵泡数量）：卵巢功能会随时间下滑，尤其潍坊35岁以上姐妹，半年内AMH可能降0.5-1.0，必须在月经第2-3天重新查，医生据此调整促排方案（比如上次用长方案，这次可能改微刺激）；

　　2. 男方精液分析（含精子活力+碎片率）：潍坊男性常因熬夜、久坐（如冬天怕冷不运动、夏天贪凉吹空调）导致精子质量波动，第一次失败后，可能因习惯改变或身体状态变化，精子碎片率升高，必须禁欲3-7天后重新查，避免因精子问题再失败；

　　3. 女方激素水平（性激素六项）：月经第2-3天查，看雌激素、促卵泡生成素（FSH）是否正常，若FSH升高，说明卵巢功能下滑，需调整促排用药剂量，这是潍坊试管医生制定方案的核心依据；

　　4. 子宫B超（阴超）：查内膜厚度、有无息肉/肌瘤/粘连，潍坊潮湿气候易导致盆腔炎症反复，可能第一次查正常，第二次出现轻微粘连，必须重新查，避免胚胎着床时“卡壳”。

　　二、重点补查：第一次失败后，潍坊姐妹必做的4项“失败排查”（关键中的关键）

　　如果第一次失败原因不明（比如胚胎优质却没着床），或失败原因明确（如内膜薄），第二次进周必须针对性补查，这4项是潍坊生殖医生公认的“失败隐患排查重点”，能帮你找到问题根源：

　　1. 宫腔镜检查（适配：第一次胚胎着床失败、内膜薄/不均）

　　这是潍坊第一次试管失败后，补查率项目（占比60%），很多姐妹第一次没做，第二次必查——通过宫腔镜直接观察宫腔内部，能发现B超查不到的轻微粘连、内膜炎症，这些都是“隐形杀手”。

　　比如潍坊32岁的王女士，第一次移植优质胚胎失败，B超显示内膜正常，第二次进周前做了宫腔镜，发现宫腔有0.5cm的轻微粘连，医生当场分离，调整内膜调理方案后，移植一次成功。

　　潍坊做宫腔镜，优先选潍坊市人民医院（无痛技术成熟，全程10分钟，费用1500-2000元，医保可报50%），月经干净后3-7天做，做完休息3-5天即可，不耽误进周进度。

　　2. 胚胎质量复盘（适配：第一次取卵少、优质胚胎少、养囊失败）

　　如果第一次促排取卵少（＜5颗）、优质胚胎少（＜2枚），或养囊失败，第二次进周前一定要让医生复盘第一次的胚胎报告——包括取卵数量、成熟率、受精率、胚胎评级，必要时查看胚胎培养过程（如是否有碎片率升高、发育停滞）。

　　潍坊潍坊市妇幼保健院有专业的胚胎实验室，医生会结合第一次的促排用药（比如上次用进口药，这次可能换国产药调整）、取卵时间，分析胚胎质量差的原因，比如是促排药剂量不够，还是取卵时机太早，避免第二次重蹈覆辙。

　　3. 免疫+凝血筛查（适配：反复着床失败、早期流产）

　　如果第一次移植后着床却早期流产，或连续2次胚胎优质却没着床，潍坊姐妹必须补查这两项，很多“隐形问题”藏在这里：

　　- 免疫筛查：查抗磷脂抗体、子宫内膜NK细胞活性，若抗磷脂抗体阳性，会导致母体把胚胎当“异物”排斥；NK细胞活性过高，会攻击胚胎，这是潍坊反复失败姐妹最常见的原因，补查费用约1500元；

　　- 凝血筛查：查D-二聚体、蛋白S/蛋白C，潍坊人爱吃重油重盐（如肉火烧、炸肉），可能导致凝血功能异常，子宫内膜血流不足，胚胎“缺血缺氧”无法着床，补查后若异常，医生会提前用抗凝药调理，提升着床率。

　　4. 子宫内膜容受性检测（ERA）（适配：3次以上着床失败、内膜厚度达标却不着床）

　　如果第一次内膜厚度达标（≥8mm），但胚胎没着床，第二次进周前建议做ERA检测——通过检测内膜细胞，找到胚胎最适合着床的“种植窗期”（比如常人是移植第5天，你可能是第6天），避免“胚胎到了，内膜还没准备好”的情况。

　　潍坊目前只有潍坊市人民医院能做ERA检测，费用约3000元，虽然比普通B超贵，但能让着床率提升30%，很多潍坊反复失败的姐妹，做完这项后第二次移植成功，性价比很高。

　　三、潍坊第二次试管进周检查：医院选择+省钱技巧（本地专属攻略）

　　- 医院选择：按“需求”选，不盲目跟风

　　1. 想排查失败原因：选潍坊市人民医院（潍坊试管“龙头”，能做ERA检测、宫腔镜，免疫筛查项目全，医生经验丰富，年试管周期超3000例）；

　　2. 想控预算+便捷：选潍坊市妇幼保健院（检查费用比市人民医院低10%-15%，有“第二次进周专属门诊”，不用抢号，护士会全程指导检查流程，适合潍坊周边县域的姐妹）；

　　3. 想中西医结合调理：选山东中医药大学附属医院潍坊医院（做完检查后，可同步用中药调理卵巢或内膜，适配潍坊潮湿气候，减少炎症反复）。

　　- 省钱技巧：3招帮你省2000-5000元

　　1. 提前整理旧报告：第一次检查的报告按“可沿用、需重新查”分类，带好去医院，避免医生误开重复检查；

　　2. 走潍坊医保报销：卵巢功能评估、精液分析、传染病筛查等项目，潍坊职工医保可报50%-70%，居民医保可报40%-50%，检查前先在医院医保窗口备案，节省不少开支；

　　3. 集中时间做检查：月经第2-3天先查卵巢功能、激素六项，月经干净后3-7天查宫腔镜、ERA，集中2周内完成所有检查，避免来回跑医院，节省交通和时间成本。
